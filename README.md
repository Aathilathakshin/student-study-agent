# Student Study Assistant AI Agent

A beginner-friendly Python project that helps students plan and track their study time.

## Features
- Calculate total study hours
- Create a simple study plan
- Divide daily study time between subjects
- Track chapter completion progress
- Save and view study progress
- Find subjects that need more attention
- Ask Gemini AI general questions

## Technologies Used
- Python
- Google Gemini API
- JSON for saving study progress

## How to Run
1. Install the required Python packages.
2. Add your Gemini API key to a `.env` file.
3. Run the app using:

   `python app.py`

## Note
The Gemini AI feature requires an internet connection and a valid API key.
# Student Study Assistant AI

A Streamlit-based AI study assistant prototype designed to help students organize and understand their study materials.

## Features
- AI-powered study chat with different explanation modes
- PDF and TXT notes upload with summarization and question answering
- AI-generated study planner
- Study progress tracker with Supabase database storage

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- Supabase

## Project Status
Working prototype. Features are being tested and improved.

## Run Locally
1. Install dependencies:
   `pip install -r requirements.txt`
2. Add the required API credentials to Streamlit secrets.
3. Run:
   `streamlit run app.py`
