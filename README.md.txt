# Student Study Assistant AI Agent

A beginner-friendly Python project that helps students plan and track their study time.

## Features
- Calculate total study hours
- Create a simple study plan
- Divide daily study time between subjects
- Track chapter completion progress
- Save and view study progress
- Find subjects that need more attention
- Ask Gemini AI general questions

## Technologies Used
- Python
- Google Gemini API
- JSON for saving study progress

## How to Run
1. Install the required Python packages.
2. Add your Gemini API key to a `.env` file.
3. Run the app using:

   `python app.py`

## Note
The Gemini AI feature requires an internet connection and a valid API key.
